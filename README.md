1. Tải bộ dữ liệu của dự án

- Link: https://archive.ics.uci.edu/dataset/602/dry+bean+dataset

- Sau khi tải xong giải nén và đưa folder DryBeanDataset vào thư mục data/raw

2. Chạy file setup.bat

- File setup.bat sẽ tạo một môi trường ảo riêng cho dự án đồng thời cài đặt các thư viện cần thiết
- Sau khi chạy xong file setup thực hiện nhấn tổ hợp phím **`Ctrl + Shift + P`** -> gõ **`Python: Select Interpreter`**
- Chọn dòng có đường dẫn **`.\.venv\Scripts\python.exe`** để vào môi trường ảo
